*** TAG

Vocês precisam registrar a história do projeto no Git. Para marcar a v0.1 na data correta (agosto/2025) sem alterar os arquivos de hoje, sigam estes passos no terminal:

Encontrar o Commit: Busquem o código hash do commit que representa o estado do projeto em 1º de Agosto (ou data próxima).

Comando: git log --before="2025-08-02" -n 10

Copiem os primeiros 7 caracteres do hash (ex: a1b2c3d).

Criar a Tag no Passado:

Comando: git tag -a v0.1 <HASH_DO_COMMIT> -m "Versão 0.1 - Estrutura de Leitura LAS"

Criar a Tag Atual:

Comando: git tag -a v0.3 -m "Versão Final com Interpretação"

Enviar para o GitHub:

Comando: git push origin --tags
