
\chapter{Etapas, Cronograma e Orçamento\label{cha: Etapas, Cronograma e Or=0000E7amento}}

\lhead{\thechapter\space - Atividades, Cronograma e Orçamento}\pagenumbering{arabic}

Este capítulo apresenta as etapas, o cronograma de execução e uma
previsão de orçamento preliminar para o desenvolvimento do sistema
GeoLogViewer, um software de apoio acadêmico para estudantes de engenharia.

\section{Etapas\label{sec: Etapas}}
\begin{itemize}
\item Etapa 0 - Definição do desafio tecnológico
\begin{itemize}
\item Identificação do problema: dificuldade de acesso a ferramentas didáticas
que leiam, interpretem e visualizem arquivos LAS; barreiras pedagógicas
para estudantes e professores na análise de perfis de poço.
\item Definição da solução esperada: software educacional leve, gratuito
e de código aberto, capaz de ler arquivos LAS, exibir curvas (GR,
RHOB, NPHI), realizar cálculos básicos (pressão hidrostática, densidade
média) e exportar gráficos/relatórios.
\item Estimativa de maturidade tecnológica (TRL): TRL 2 ao iniciar o projeto
(conceito formulado).
\end{itemize}
\item Etapa 1 - Elaboração do pré-projeto
\begin{itemize}
\item Produção da versão inicial do documento, contendo: escopo detalhado;
levantamento preliminar de requisitos (fundamentais e desejáveis);
estudo de viabilidade técnica (ferramentas, bibliotecas gráficas,
compatibilidade); e protótipos iniciais da interface.
\item Definição de critérios de sucesso: formatos de entrada suportados,
tipos de curva, formatos de exportação e metas de desempenho em máquinas
de média capacidade.
\end{itemize}
\item Etapa 2 - Elaboração do projeto - detalhamento e contrato
\begin{itemize}
\item Definição das funcionalidades completas
\item Detalhamento das classes
\item Divisão de responsabilidades na equipe: backend (parsing e cálculos),
frontend (interface e renderização), testes e documentação.
\end{itemize}
\item Etapa 3 - MModelagem de engenharia: 
\begin{itemize}
\item Modelagem orientada a componentes, produzindo: diagramas de casos
de uso, diagrama de pacotes e diagrama de classes.
\item Definição da arquitetura modular (camadas: entrada de dados, processamento/ciência,
apresentação) para garantir reuso e extensibilidade.
\item Validação dos modelos com revisões de projeto e testes de protótipo
rápido (proof-of-concept) para os parsers LAS.
\end{itemize}
\item Etapa 4 - Ciclos de planejamento, detalhamento e construção/implementação: 
\begin{itemize}
\item O projeto foi dividido em ciclos incrementais:
\item v0.1 -- Núcleo de dados e leitura de arquivo
\item v0.3 -- Plotagem de curvas de diferentes perfis
\item v0.7 -- Interpretação de áreas de interesse
\end{itemize}
\item Etapa 5 - Entrega do produto:
\begin{itemize}
\item Testes finais de uso com diferentes perfis de poços.
\item Geração dos manuais de uso.
\item Entrega do executável e dos arquivos-fonte com instruções de compilação
no GitHub.
\end{itemize}
\end{itemize}
